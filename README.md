TextHighlightDiff 文本高亮对比工具 - README

## 📌 项目简介

**TextHighlightDiff** 是一款基于 Python 内置 Tkinter 开发的 **轻量图形化文本差异对比工具** ，无需安装任何第三方依赖，开箱即用。专门用于快速对比两段文本的异同，通过**彩色高亮标注**直观展示文本多字、少字、字符不一致等差异问题，适合文案校对、代码比对、文档审核、作业核对等日常场景使用。

工具主打 **可视化高亮差异** ，告别传统纯文字描述对比结果，所有不同内容精准定位、颜色区分，一目了然。

## ✨ 核心功能

* **零依赖运行** ：基于Python内置Tkinter库，无需pip安装插件，原生支持Windows、MacOS、Linux
* **双栏可视化输入** ：左右分栏布局，分别放置【原始文本】和【对比文本】，支持滚轮滚动、无限输入
* **精准差异检测** ：支持逐行、逐字符智能比对，精准识别：多余内容、缺失内容、内容不符三类差异
* **彩色高亮标注** （核心特色）
* 🔴 **红色** ：标记对比文本中**多余新增**的内容
* 🔵  **蓝色** ：标记原始文本中**被缺失/删除**的内容
* 🟡  **黄色** ：标记两段文本**字符不一致**的差异内容
* **数据统计输出** ：自动统计差异总数、多余字数、缺失字数、不符内容数量，清晰展示对比结果
* **一键清空重置** ：支持一键清空双栏文本和所有高亮标记，快速进行下一次对比
* **自适应界面** ：窗口布局规整，组件自适应缩放，操作简洁直观

## 💻 运行环境

* Python 3.6 及以上版本
* 无需安装第三方库（全程使用Python内置标准库）
* 支持系统：Windows / MacOS / Linux

## 🚀 使用教程

### 1. 程序运行方式

将源码文件保存为 `TextHighlightDiff.py`，打开终端/CMD，进入文件所在目录，执行以下命令运行程序：

```Plain
python TextHighlightDiff.py
```

### 2. 操作步骤

1. **输入文本** ：在左侧【原始文本】框粘贴/输入基准文本，右侧【对比文本】框输入需要校验的文本
2. **开始对比** ：点击界面【检查差异】按钮，程序自动扫描并高亮所有差异内容
3. **查看结果** ：通过红/蓝/黄三色高亮识别差异位置，底部查看详细差异统计数据
4. **重置操作** ：点击【清空全部】按钮，清除所有文本和高亮标记，重新开始对比

## 🎨 高亮规则说明

| 高亮颜色                                                 | 差异类型 | 场景说明                                |
| -------------------------------------------------------- | -------- | --------------------------------------- |
| -------------------------------------------------------- |          |                                         |
| 红色                                                     | 多余内容 | 对比文本存在、原始文本没有的新增内容    |
| -                                                        | -        | -                                       |
| 蓝色                                                     | 缺失内容 | 原始文本存在、对比文本被删除/缺失的内容 |
| 黄色                                                     | 内容不符 | 两段文本同一位置字符、文字不一致的内容  |
